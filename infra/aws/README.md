# AWS on-demand infrastructure

This Terraform configuration creates encrypted quarantine/clean storage, a GuardDuty malware-tag gate, an SQS worker with a redrive queue, Cognito/API Gateway routes, private UI storage behind an enabled CloudFront OAC, and observability primitives that are safe to review in a plan. The quarantine bucket has callback-origin-scoped POST CORS for presigned browser uploads. SQS uses SQS-managed SSE so the S3 notification policy can authorize delivery; document S3 upload/read/copy and GuardDuty paths use the documents CMK with scoped `kms:GenerateDataKey`/`kms:Decrypt` permissions. The Lambda timeout is 30 seconds and SQS visibility is 300 seconds; async Textract job state is persisted in DynamoDB and retried through SQS. The quarantine `ObjectCreated` notification is the only AWS enqueue path; `/process` acknowledges it without sending another message. Never apply from a pull request.

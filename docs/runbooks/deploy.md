# Ephemeral AWS deploy

Create or select an encrypted S3 remote-state bucket and DynamoDB lock table, then configure the protected environment variables `AWS_TF_STATE_BUCKET`, `AWS_TF_STATE_KEY`, and `AWS_TF_LOCK_TABLE`. Review the Terraform plan and cost model, select the protected environment, and dispatch exactly one typed action confirmation (`PLAN`, `APPLY`, `SMOKE`, or `DESTROY`). The GuardDuty role follows the [official Malware Protection for S3 IAM prerequisite](https://docs.aws.amazon.com/guardduty/latest/ug/malware-protection-s3-iam-policy-prerequisite.html), including its scoped managed EventBridge rule actions, S3 validation/notification/version permissions, and S3-scoped KMS ViaService condition. Apply derives the CloudFront URL, completes the Cognito PKCE callback configuration, builds the UI with same-origin API paths, and uploads it to the private UI bucket. Execute smoke with a short-lived Cognito ID token and synthetic fixture; the script sends an exact-size browser-equivalent SHA-256 contract, polls to a terminal state, checks citations/confidence and audit, performs review correction, deletes, asserts 404, and uploads only a sanitized artifact. Run destroy and verify the Terraform state and outputs are absent. A release is not cloud-verified unless these checks succeed; AWS remains unexecuted in this repository.
